## Мои ошибки (заполняю по ходу недели)

- 04.11, тема 1^∞ (задания 5, 7, демо №4): при x → ∞ дробь вида (x + 2)/(x + 4) считала → 0 (или → 1 «на глаз»), а это неопределённость ∞/∞. Правило: делим на старшую степень; степени равны → отношение старших коэффициентов, например (6x + 1)/(4x − 7) → 6/4 = 3/2; степень числителя меньше → 0; больше → ∞. Теория: Практика 3, задачи 277–292; Лекция 1 (пример с 3/5).
- 04.11, (2x − 1)/(x² + 3) при x → ∞: числитель поделила на x, а знаменатель на x² — так нельзя, дробь меняется (6/4 ≠ (6/2)/(4/4)). Числитель и знаменатель делим на **одну и ту же** степень — старшую во всей дроби.
- 04.11, запись 1^∞: писала lim (u − 1)^v вместо исходного выражения и пропускала «e^( … )» в середине цепочки. Цепочка: lim u^v = e^( lim v · (u − 1) ) = … = e^(число).
- Разминка (Горнер + ловушка 1): lim x→1 (x³ − 3x + 2)/(x² − 2x + 1) — не обратила внимания на степень 3 → перед разложением перечитать степень и выписать все коэффициенты, включая нулевые.
