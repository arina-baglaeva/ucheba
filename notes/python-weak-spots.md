# Мои слабые места в Python

Пополняю по ходу Практикума и проектов. Формат: что путаю → как правильно → откуда привычка.

## Привычки из Java

- **Склеить список строк через разделитель:** `", ".join(список)`, а не `String.join(", ", список)`. Разделитель — объект, у которого вызывают метод. Перепутала → `AttributeError: 'list' object has no attribute 'join'`. Работает только со строками. (19.11, практика #1 PokéAPI)
- **Классы:** объект создаётся без `new`: `Book(...)`, а `new Book(...)` → `SyntaxError`. `self` пишется **первым параметром каждого метода** (в Java `this` неявный). Атрибуты создаются в `__init__` через `self.title = title`: без `self.` это локальная переменная, которая пропадёт. Забыла `self` в параметрах → `TypeError: ... takes 0 positional arguments but 1 was given`. (19.11, ООП к проекту)

## Остальное

- Словарь: `d["key"]` падает с `KeyError`, если ключа нет; `d.get("key")` молча возвращает `None` и прячет ошибку в пути к данным. При отладке вложенных словарей печатать промежуточные части: `print(r["types"][0])`. (19.11)
