# План самообучения: путь к ML-инженеру

Старт: **02.11.2026**. Сроки этапов примерные: на ретро в субботу сверяемся и сдвигаем их, если нужно.

## Принципы

- **Регулярность важнее объёма.** Пн–Сб по ~3 ч (в план кладём ~2,5 ч + буфер), воскресенье полностью свободно.
- **Правило 70/30.** Не больше 30% времени на курсы и видео, остальное — задачи и свои проекты.
- **Всё в GitHub.** Это будущее портфолио.
- **ИИ — репетитор, а не исполнитель.** Объясни, проверь, найди ошибку — но код пишу сама.
- **Учёба в приоритете.** Математика из вуза — это и есть база для ML. Пары «Анализ данных» и «Программирование» связываю с самообучением.
- **Без фронтенда.** Проекты — консоль, данные, модели, API.

## Этап 1. Фундамент программиста (ноябрь 2026 — январь 2027)

Цель: из «знаю синтаксис, но путаю с Java» стать человеком, который уверенно пишет программы.

- [ ] **Диагностика:** найти слабые места в Python и привычки из Java (неделя 1).
- [ ] **Python глубже синтаксиса:** типы и изменяемость, коллекции, функции (`*args`, `**kwargs`, области видимости), исключения, файлы, comprehensions, модули, виртуальные окружения (`venv`, `pip`).
- [ ] **ООП в Python по сравнению с Java:** классы, `self`, dunder-методы, `@dataclass`, наследование, утиная типизация.
- [ ] **Качество кода:** PEP 8, type hints, `pytest`, отладчик VS Code.
- [ ] **Алгоритмы:** 3–5 задач в неделю (LeetCode, Яндекс Контест, Stepik). O-нотация, хеш-таблицы, стек/очередь, сортировки, бинарный поиск, рекурсия, графы (BFS/DFS).
- [ ] **Инструменты:** Git (ветки, коммиты, слияние, конфликты, pull request), командная строка, VS Code.
- [ ] **SQL, основы:** SELECT, WHERE, GROUP BY, JOIN (SQLite из Python).
- [ ] **Математика вуза:** матан, алгебра, дискретка — не отставать по парам.

**Результат:** 2–3 небольших консольных проекта на GitHub (с классами, тестами, нормальной историей коммитов) и 30–50 решённых задач.

Ресурсы: хендбук Яндекса «Основы Python» (education.yandex.ru/handbook/python), docs.python.org/3/tutorial, Pro Git на русском (git-scm.com/book/ru/v2), learngitbranching.js.org.

## Этап 2. Данные и статистика (февраль — апрель 2027)

- [ ] **Jupyter, NumPy, pandas, matplotlib/seaborn** на реальных датасетах (Kaggle).
- [ ] **SQL:** запросы, JOIN, группировки, подзапросы, оконные функции.
- [ ] **Теория вероятностей и статистика:** распределения, ЦПТ, доверительные интервалы, проверка гипотез, A/B-тесты.
- [ ] **Математика для ML:** векторы и матрицы, производная и градиент.
- [ ] **Проба аналитики:** исследование датасета с выводами.

**Результат:** 2 аналитических проекта (EDA с выводами), уверенный SQL.

Ресурсы: Kaggle Learn (Pandas, Data Visualization), хендбук Яндекса по математике для анализа данных, 3Blue1Brown «Essence of linear algebra».

## Этап 3. Классическое машинное обучение (май — июль 2027)

- [ ] **Теория ML:** линейная и логистическая регрессия, kNN, деревья, ансамбли (случайный лес, бустинг), кросс-валидация, метрики, переобучение и регуляризация.
- [ ] **Сама реализовать** градиентный спуск для линейной регрессии на NumPy — чтобы понимать, что внутри.
- [ ] **Практика:** scikit-learn (`Pipeline`, feature engineering), CatBoost/LightGBM, 1–2 соревнования на Kaggle.
- [ ] **Проект «модель → API (FastAPI) → Docker → деплой».**

**Результат:** понимание основных алгоритмов ML, проект в продакшене.

Ресурсы: хендбук Яндекса «Машинное обучение» (education.yandex.ru/handbook/ml), mlcourse.ai (ODS), User Guide scikit-learn.
